# Freewyld — Engineering Exercise

A small Python revenue-tooling project. This is a short, live exercise (~20 minutes)
that you'll work through using **Claude Code** while sharing your screen.

## Setup

No third-party dependencies — Python 3 standard library only.

```bash
python3 run.py           # see what the tool currently outputs
python3 test_report.py   # the checks you need to make pass
```

## Your task

Use **Claude Code** to get `python3 test_report.py` to pass, and to make the code
behave according to the standards in `CLAUDE.md`. Work however you normally would with
the agent, and please narrate what you're asking it and why.

Full brief: see `TASK.md`.
